One line of awkward small talk one robot says to another while they ride an elevator together: a machine that simulated the ride 4,000 times and still has no idea what to do with its arms.

> I ran 4,000 simulations of this elevator ride. In every one of them, I still had no idea what to do with my arms.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (or `$OUTPUT_PATH` when set). The line is validated before writing: 1–200 characters, a single line, no control characters, not only whitespace.
